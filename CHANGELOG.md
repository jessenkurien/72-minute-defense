# Changelog

All notable changes to this project will be documented here.

## Unreleased

- Clarified the community/reference and commercial engagement boundaries, added a prominent
  dry-run and review notice, and expanded private vulnerability-reporting and supported-version
  guidance.
- Added durable creator attribution to generated JSON, Markdown, SVG, and dashboard artifacts.
- Added `CITATION.cff`, international-use guidance, discoverability language, and a social-preview asset.
- Pinned GitHub Actions to immutable commits and added an installed-wheel smoke test.
- Updated Defender for Endpoint requests to Microsoft's current unified API hostname while retaining the documented legacy token resource.
- Modernized package metadata and made the security-response language sustainable for a volunteer-maintained project.

## 0.1.0 — release candidate

- Four-tier containment authority policy with illustrative digest attestations and an unarmable public template.
- ATT&CK-aligned precursor scoring, business-context decisioning, and the fallback rule: do what is pre-authorized now; escalate the rest.
- Dry-run adapters for Entra ID, Defender for Endpoint, Okta, CrowdStrike Falcon, and AWS.
- Sentinel, Splunk, Falcon, and GuardDuty intake normalization.
- Hash-chained audit records and four deterministic synthetic rehearsals.
- Executive, GRC, privacy, tabletop, delivery, architecture, threat-model, and launch documentation.
